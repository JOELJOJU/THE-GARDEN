# THE-GARDEN


:triangular_flag_on_post: This project is an e-commerce platform named "The Garden" designed to facilitate the online
sale of plants . 

:triangular_flag_on_post: Developed using PHP, MySQL, HTML, CSS, and JavaScript, the website
offers a user-friendly experience for customers to browse, search, and purchase a wide variety
of products. 

:triangular_flag_on_post: The platform includes essential features such as user authentication, product
management, a shopping cart, and a secure checkout process.

:triangular_flag_on_post: An admin dashboard allows for efficient product management. 

:triangular_flag_on_post: The project aims to enhance accessibility and streamline the shopping experience for gardening enthusiasts, providing a convenient digital solution for both users and administrators.
